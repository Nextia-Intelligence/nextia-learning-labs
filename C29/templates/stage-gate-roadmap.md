# Stage-gate roadmap

*Module 3, lesson 2. AI work is planned as experiments with a time limit. Each stage ends at a gate: a meeting where the owner looks at the evidence and decides to continue, change or stop. Write the evidence to pass and the result that stops the work **before** the stage starts.*

**Product:**
**Owner who decides at every gate:**

| Stage | Question it answers | Time box | Evidence to pass the gate | Result that stops or changes the work | Who decides |
|---|---|---|---|---|---|
| 1. Feasibility | Can AI do this task on our examples at all? | | | | |
| 2. Pilot | Does it work for real users, with review, at an acceptable cost? | | | | |
| 3. Limited launch | Does it work in operation, for a small share of real work? | | | | |
| 4. Full launch | Does it keep working for everyone, and do we watch the right signals? | | | | |

## Rules

- A stage has a time box, not a delivery date. At the end of the time box, the gate meets, even if the work is not finished.
- "Stop" is a good result when the evidence says so. It saves the cost of the next stages.
- A gate's thresholds come from the [definition of done](definition-of-done.md).
- Write each gate decision in a [decision record](decision-record.md).
