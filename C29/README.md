# Leading AI Products and Teams

Files for the course [Leading AI Products and Teams](https://learning.nextia-ai.com/courses/ai-leadership/). There is no code here. You read tables, short reports and cost estimates, and you fill in templates in your own document tool.

## What you need

A browser, and a document tool: a word processor, a text editor or a spreadsheet. You need no account, no installation and no money.

To use a template, open it on this page, copy its text into your own document, and fill it in. To get every file at once, download this repository as a ZIP file (the green **Code** button, then **Download ZIP**) and open the folder of this course (the folder that has this README). The `.md` files are text files: any text editor opens them. The `.csv` files open in any spreadsheet.

## How to read the numbers

Every number in these files has one of four labels. Read the label before you use the number.

| Label | What it means | Example |
|---|---|---|
| **recorded** | Measured in a run that an earlier course made and saved. The source names the course. | Prompt v2 caught 24 of 24 holdout tickets that needed a person. |
| **price** | A published list price. Prices change: check the current page. | A provider's list price to host a fine-tuned small model: US$1.70 an hour. |
| **assumption** | A value we chose, with a low, base and high range. Change it if you know better. | An agent needs 4 / 6 / 8 minutes to write a reply by hand. |
| **constructed** | A situation, a company or a document written for the course. It is realistic, not real. | The vendor ReplyRight and its offer. |

The tickets, receipts, vendors, partners and projects in these files are made up for the courses. No real customer, company or person is in them. The model replies in the error examples are real replies, recorded from real models.

## Check your files (the course's first step)

Open these three files and find one named figure in each. If you find all three, your files are complete.

1. [`evidence/pilot-evidence-pack/README.md`](evidence/pilot-evidence-pack/README.md): how many holdout tickets that needed a person did the cheaper prompt v3 catch? (Answer: 23 of 24.)
2. [`templates/value-estimate.csv`](templates/value-estimate.csv): what is the base value of `minutes_to_write_a_reply_by_hand`? (Answer: 6.)
3. [`evidence/use-case-cards.md`](evidence/use-case-cards.md): how many cards are there? (Answer: 8.)

If a file is missing or does not open, download the ZIP file again. You cannot break anything: these are copies. To start again with a template, copy it again from this page.
