This folder holds the model's small files, unchanged, from that revision: `config.json`,
`generation_config.json`, `tokenizer.json`, `tokenizer_config.json` and `special_tokens_map.json`.
They are here so that you can count parameters (Module 3) and run the tests without a download.
The weights (`model.safetensors`) are not here: `python -m adapt download` gets them from the
Hub at the pinned revision (Module 4).
