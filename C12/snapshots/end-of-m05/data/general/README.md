# General questions (a small regression check)

20 short questions that have nothing to do with support tickets, each with the words that a right
answer contains (`expected_any`, compared without capital letters, except g10). They were written for
this course by the course author. They check one thing only: does the model still answer ordinary
questions as text after we add the adapter, or has it learned to answer everything with ticket JSON?
20 questions are far too few to measure general ability; they can only show a large loss.
