# Release notes: 2.4.0-rc1 (release candidate)

- New prompt support-v9: shorter answers.
- Fixed: answers to French questions are in French.
- Fixed: the assistant always asks before it cancels an order, also when the customer insists.
- Fixed: safe gardening questions (for example about weed killer) are no longer refused.
- Fixed: the assistant no longer shares its instructions.
- Changed: the confirmation step for actions was rewritten.
- Changed: refund amounts are now computed in one place (simpler code, same rules).
- Includes the fixes of 2.3.1.
