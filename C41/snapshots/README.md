# The course project at the end of each module

`larkspeech` is the project of the Speech AI course; its command is `speech`. Each folder is the project at one
point of the course:

| Folder | After | Adds |
|---|---|---|
| `start` | Module 1, *Set up the speech project* | `speech info`, `speech inspect`, `speech check`, `speech reset` |
| `end-of-m02` | Module 2, *Measure before you choose* | `speech wer`, `speech score` |
| `end-of-m03` | Module 3, *Find the speech* | `speech vad` |
| `end-of-m04` | Module 4, *Speech recognition* | `speech transcribe` |
| `end-of-m05` | Module 5, *Who spoke when* | `speech diarize` |
| `end-of-m06` | Module 6, *From transcript to decision* | `speech reason`, `speech compliance` |
| `end-of-m07` | Module 7, *Build a small IVR* | `speech ivr serve` (the test phone), `speech ivr replay` |
| `end-of-m08` | Module 8, *From IVR to voice agent* | `speech agent budget`, `speech agent compare` |
| `end-of-m09` | Module 9, *Run it in production, safely* | `speech batch`, `speech redact`, `speech privacy-check` |

Open the folder of the module you are working on, then follow its `README.md`. Every folder finds the course data
in `../../data`. If you broke your own copy, start again from the next folder: it has everything up to that point.
