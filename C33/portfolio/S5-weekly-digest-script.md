# System card S5: Weekly digest script

> **Constructed** for this course: Larkfield, its people and this card are made up. Some fields are wrong or empty on purpose. Your task is to find them.

| Field | As written on the card |
|---|---|
| System | Weekly digest script |
| Kind | Found by the platform team; nobody registered it |
| What it does | A script found in a shared folder. Each week it sends the customer messages of the week to an AI service and e-mails a summary of complaints to a mailing list. |
| Who uses it | A mailing list of 14 people |
| Who it affects | Every customer who wrote that week |
| Accountable owner | **(nobody named)** |
| Technical owner | **(nobody named)** |
| Who approves changes and actions | **(nobody named)** |
| Data it uses | Customer messages with names and order numbers |
| Model | An AI service that Larkfield has no contract with, called with a personal key |
| What it may do alone | Writes a summary for people; decides nothing |
| In the platform registry | no |
| Vendor check | none |
| Last review | never |
| Note | The key belongs to a contractor who has left Larkfield. |

## Questions to ask about this card

1. Is the accountable owner one named person who can say yes or no?
2. Who approves a change, and who approves an action that affects a customer?
3. What data goes where, and is there a contract for it?
4. What would a wrong result cost, and who would notice?
