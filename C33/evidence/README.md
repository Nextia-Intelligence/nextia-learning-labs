# The evidence pack

What an auditor, a customer or the board can ask Larkfield to show, and the records that answer.

| File | What it is | Label |
|---|---|---|
| [earlier-courses.md](earlier-courses.md) | Results recorded by earlier courses of Nextia Learning on Larkfield's systems: approvals and refunds, the release gate, a post-incident review, security testing | recorded (the situations around them are constructed) |
| [registry-extract.md](registry-extract.md) | The platform registry's records of the registered systems | constructed |
| [usage-report.md](usage-report.md) | One month of use and cost per system, and the unregistered spend on a provider bill | constructed from recorded unit costs and assumed volumes |
| [audit-requests.md](audit-requests.md) | Five requests from an auditor | constructed |

Evidence is good when it was made by the work itself (a log, a registry entry, an approval record, a signed decision), when it is current, and when it covers the period that was asked about. A document written for the audit is a description, not evidence.
