# Decision record

One page per decision that changes what an AI system may do: a launch, a new use, more autonomy, a vendor, an exception. Write it when the decision is made, not later.

| Field | Write |
|---|---|
| ID | |
| Decision | One sentence |
| System and tier | |
| Requested by | |
| Decided by | Name and role; for the board, who was present |
| Options considered | Including "no" and "not yet" |
| Evidence used | Links: evaluation, impact assessment, vendor answers |
| Conditions | Each with an owner and a check |
| What would change this decision | |
| Review | When, or after what event |
