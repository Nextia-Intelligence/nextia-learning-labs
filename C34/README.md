# Anomaly Detection: Find What Is Unusual

Materials for the course *Anomaly Detection: Find What Is Unusual* on
[learning.nextia-ai.com](https://learning.nextia-ai.com).

## What is in this folder

| Folder or file | What it is |
|---|---|
| `notebooks/` | One folder per lesson: the learner notebook and its solution. Open them in Colab, Kaggle or VS Code. |
| `data/` | The Larkfield data of the course (synthetic), its dataset card and its checksums. |
| `compare.py` | The comparison table: it scores any detector on the same data, in the same way. |
| `features.py` | The behaviour features of the payments (Module 4 builds them). |
| `detection-job/` | The finished detection job of Module 9. |
| `snapshots/` | The detection job at the start of Module 9 and at its end. |
| `recordings/` | Recorded answers of a real language model (Module 6, lesson 3). |
| `final-assignment/` | The data of the final assignment. |

Every notebook downloads what it needs by itself, so you do not need to copy anything first. To work on your own
computer, use Python 3.12 and the versions in `requirements.txt`.

All data here is made up for the course. It has no real people, cards or payments. The unusual events in it are
ones we planted on purpose.
