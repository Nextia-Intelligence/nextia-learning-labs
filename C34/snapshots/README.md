# The detection job: snapshots

Two copies of the detection job of Module 9 (*Run a detector in production*):

| Folder | When to use it |
|---|---|
| `start/` | At the start of Module 9. The job can learn "normal" and score a day: 7 tests. |
| `end-of-m09/` | At the end of Module 9: alerts with reasons, the daily budget, runs that never send an alert twice, the drift check, reviews, the snooze rule and the weekly report: 19 tests. The same as `../detection-job/`. |

Copy `start/` to your own folder, for example `projects/detection-job`, and follow its README. If your copy
breaks, compare it with `end-of-m09/`, or start again from a fresh copy.
